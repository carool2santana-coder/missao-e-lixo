# ♻️ Missão E-Lixo: Guia de Descarte Consciente com a Teka

Projeto educativo de sustentabilidade e tecnologia desenvolvido para conscientizar crianças sobre a importância do descarte correto do lixo eletrônico (E-Lixo).

## 📖 Sobre o Projeto
O **Missão E-Lixo** é uma aplicação web interativa e lúdica. Guiadas pela personagem **Teka**, as crianças aprendem os perigos dos metais pesados presentes nos eletrônicos, os 4 caminhos conscientes (Reutilizar, Consertar, Doar, Descartar) e testam os seus conhecimentos num minijogo interativo. Ao final, recebem um "Certificado de Defensor da Natureza" personalizado.

## 🔄 Resiliência e Adaptação Ágil (A História do Projeto)
No desenvolvimento de software e gestão de projetos, a capacidade de adaptação a cenários reais é fundamental. Este projeto é um exemplo prático dessa agilidade:

- **O Escopo Inicial:** O projeto foi desenhado originalmente para ser aplicado de forma presencial em duas escolas na região de Diadema - SP.
- **O Desafio:** Face à recusa das instituições escolares em adotar a iniciativa, o plano de execução precisou ser revisto de forma imediata para que a ação social não fosse perdida.
- **A Readaptação (O Pivot):** O projeto foi inteiramente redesenhado para o **âmbito domiciliar e comunitário**, focando no atendimento direto às crianças e famílias da comunidade de **Heliópolis e região do Sacomã**.

O código, os panfletos físicos e os mapas do site foram atualizados para refletir essa nova realidade local (incluindo pontos como o Ecoponto Comandante Taylor e o CEU Meninos). Essa mudança não só manteve o projeto vivo, como o aproximou ainda mais da realidade da comunidade, cumprindo plenamente o seu papel de ação de extensão.

## 🎮 Funcionalidades
- **Apresentação Interativa:** Slides narrados integrados à interface contando a história da Teka (preparado para integração de áudios via ElevenLabs).
- **Minijogo do Descarte:** Sistema interativo onde a criança avalia imagens reais e separa os resíduos (E-lixo, Orgânico e Reciclável) em lixeiras visuais.
- **Certificado Dinâmico:** Geração de um diploma personalizado com o nome da criança, formatado automaticamente para impressão (A4 paisagem).
- **Guia de Geolocalização:** Mapeamento prático com links diretos para o Google Maps, indicando os pontos de coleta reais e ativos na região do Sacomã/Heliópolis.

## 🛠️ Tecnologias Utilizadas
- **HTML5:** Estruturação semântica.
- **CSS3:** Design responsivo, paleta de cores acessível, animações nativas e interface *kid-friendly*.
- **JavaScript (Vanilla):** Lógica de progressão dos slides, validação do jogo, manipulação do DOM e Web Audio API (efeitos sonoros e feedbacks auditivos).
